--------------------------------------------------------------------------------
A1. Software များ အရင် install / ဖွင့်ထားရမယ်
--------------------------------------------------------------------------------

  [ ] 1. Node.js 20 သို့မဟုတ် အထက်
        - စစ်ရန်:  node -v
        - စစ်ရန်:  npm -v
        - မရှိရင်: https://nodejs.org မှ LTS version download

  [ ] 2. Docker Desktop (Windows)
        - Postgres + Redis အတွက် မရှိမဖြစ်
        - Install ပြီးနောက် Docker Desktop ကို ဖွင့်ထားရမယ်
        - စစ်ရန်:  docker -v
        - စစ်ရန်:  docker compose version
        - Desktop UI မှာ status က Running / Engine running ဖြစ်နေရမယ်

  [ ] 3. Git (clone လုပ်မယ်ဆို)
        - စစ်ရန်:  git --version

  [ ] 4. Terminal (PowerShell သို့ Command Prompt)
        - project folder ထဲ cd ဝင်နိုင်ရမယ်

  [ ] 5. (Optional) API client
        - Browser, Postman, Insomnia, သို့ PowerShell Invoke-RestMethod

  မှတ်ချက်:
    - PM2 က npm install လုပ်ရင် project ထဲ အလိုအလျောက် ပါလာမယ်
      (global install မလို)

A4. Environment file (.env) ပြင်ဆင်ခြင်း
--------------------------------------------------------------------------------

  [ ] .env ရှိ/မရှိ စစ်ပါ

    မရှိရင်:

      copy .env.example .env

    PowerShell:

      Copy-Item .env.example .env

  [ ] .env ထဲ အရေးကြီးသော တန်ဖိုးများ (local default):

    DATABASE_URL=postgresql://postgres:postgres@localhost:5432/app_db
    DB_HOST=localhost
    DB_PORT=5432
    DB_USER=postgres
    DB_PASS=postgres
    DB_DATABASE=app_db

    REDIS_URL=redis://localhost:6379
    REDIS_HOST=localhost
    REDIS_PORT=6379

    JWT_SECRET=change-me-in-production

  မှတ်ချက်:
    - .env က git မတင်ပါ (.gitignore)
    - Local app က localhost ကို သုံးသည်
    - Docker app containers က host အမည် postgres / redis ကို သုံးသည်

################################################################################
  အပိုင်း B — အဆင့်လိုက် Start လုပ်နည်း (Step by step)
################################################################################


--------------------------------------------------------------------------------
STEP 1 — Docker Desktop ဖွင့်ပါ
--------------------------------------------------------------------------------

  1. Start Menu မှ Docker Desktop ဖွင့်
  2. Engine ready ဖြစ်သည်အထိ စောင့်
  3. စစ်ရန်:

       docker info

     Error မထွက်ရင် OK


--------------------------------------------------------------------------------
STEP 2 — Postgres + Redis (Infrastructure) စတင်ပါ
--------------------------------------------------------------------------------

  backend folder ထဲမှာ:

    npm run docker:infra

  ဘာဖြစ်မလဲ:
    - ceir-postgres container စမယ် (:5432)
    - ceir-redis container စမယ် (:6379)
    - network ceir-net သုံးမယ်

  စစ်ဆေးရန်:

    docker ps --filter "name=ceir-"

  Status မှာ (healthy) ဖြစ်သည်အထိ စောင့်ပါ။

  သီးသန့် စချင်ရင်:

    npm run docker:db
    npm run docker:redis

  ရပ်ချင်ရင်:

    npm run docker:infra:down


--------------------------------------------------------------------------------
STEP 3 — Database migrate + seed
--------------------------------------------------------------------------------

  Tables မရှိသေးရင် / ပထမဆုံး setup ဆိုရင် မဖြစ်မနေ လုပ်ပါ။

  တစ်ခါတည်း:

    npm run db:setup

  သို့မဟုတ် ခွဲလုပ်:

    npm run db:migrate    → schema / tables / enums ဖန်တီး
    npm run db:seed       → demo data ထည့်

  SQL ဖိုင်များ:

    database\migrations\001_init_schema.sql
    database\seeds\001_seed.sql

  အောင်မြင်ရင် terminal မှာ တွေ့ရမယ်:

    [migrate] applied 001_init_schema.sql
    [migrate] done
    [seed] applied 001_seed.sql
    [seed] done

  Seed ထဲပါမယ့် demo data (အဓိက):

    - User: maung@dealer.com / secret123
    - Devices: IMEI 359876543210108 စသည်
    - NRC regions / townships
    - Sample activities


--------------------------------------------------------------------------------
STEP 4 — Application services စတင်ပါ (PM2 အကြံပြု)
--------------------------------------------------------------------------------

  Infra healthy + migrate/seed ပြီးမှသာ လုပ်ပါ။

  ★ အကြံပြုနည်း — PM2 (background, auto-restart):

    npm run pm2:start

  စစ်ရန်:

    npm run pm2:status

  Status က online ဖြစ်နေရမယ် (service ၁၀ ခု)။

  Log ကြည့်ရန်:

    npm run pm2:logs

  Config ဖိုင်: ecosystem.config.cjs
  Log ဖိုင်များ: logs\<service>-out.log / logs\<service>-error.log

  ---- PM2 command အပြည့် ----

    npm run pm2:start      → စတင်
    npm run pm2:status     → စာရင်း / online|errored
    npm run pm2:logs       → live logs
    npm run pm2:restart    → အားလုံး restart
    npm run pm2:reload     → zero-downtime reload (ဖြစ်နိုင်ရင်)
    npm run pm2:stop       → ရပ် (list မှာ ကျန်)
    npm run pm2:delete     → process list ကနေ ဖျက်
    npm run pm2:flush      → log ရှင်း

  ---- အခြားနည်း — foreground (dev:all) ----

    npm run pm2:delete     (PM2 နဲ့ တပြိုင်နက် မစပါနှင့်)
    npm run dev:all

  Terminal ထဲ log တိုက်ရိုက်မြင်ရမယ်။ ရပ်ရန် Ctrl+C။

  စတင်မယ့် services:

    Name                 Port    Role
    -------------------  ------  ----------------------------------
    api-gateway          3000    Public API entry
    bff                  3002    Backend-for-frontend
    auth-service         3010    Login / refresh / device binding
    users-service        3011    Profile / dealer verify
    devices-service      3012    IMEI check
    tax-service          3013    Tax applications
    payments-service     3014    Payments / batches
    claims-service       3015    Device claims
    activities-service   3016    Recent activities
    nrc-service          3017    NRC townships

################################################################################
  အပိုင်း G — Troubleshooting
################################################################################

  Docker daemon is not running
    → Docker Desktop ဖွင့်ပြီး Ready ဖြစ်အောင် စောင့်

  Port already in use
    → 5432 / 6379 / 3000–3017 ကို ယူထားတဲ့ process/container ရပ်
    → npm run pm2:status / docker ps ကြည့်
    → npm run pm2:delete  သို့  docker stop <name>

  PM2 status = errored / stopped
    → npm run pm2:logs
    → logs\*-error.log ဖတ်
    → Postgres/Redis healthy ဖြစ်/မဖြစ် စစ်
    → npm run pm2:delete ပြီး npm run pm2:start ပြန်စ

  DATABASE_URL connection failed / [db] error
    → npm run docker:infra
    → ceir-postgres healthy ဖြစ်မှ app ပြန်စ
    → .env ထဲ DATABASE_URL မှန်/မမှန် စစ်

  Redis connection failed
    → ceir-redis healthy ဖြစ်/မဖြစ် စစ်
    → REDIS_URL=redis://localhost:6379

  relation "users" does not exist
    → npm run db:setup ပြန်လုပ်

  Login 401 INVALID_CREDENTIALS
    → email/password မှန်အောင် ရိုက်
    → npm run db:seed ပြန်လုပ်

  ACCOUNT_BOUND_TO_OTHER_DEVICE (403)
    → တူညီတဲ့ deviceFingerprint ပြန်သုံး
    → သို့မဟုတ် DB ထဲ user_device_bindings row ကို ဖျက်

################################################################################
  အပိုင်း J — Ubuntu deploy (/opt/ceir/backend) + PM2
################################################################################

  Production folder:

    /opt/ceir/backend

  ecosystem.config.cjs က အောက်ပါအတိုင်း root ကို ရွေးသည်:

    1) CEIR_HOME env ရှိရင် အဲ့ path
    2) /opt/ceir/backend/package.json ရှိရင် → /opt/ceir/backend
    3) မဟုတ်ရင် → config ဖိုင်ရှိရာ folder (__dirname)


--------------------------------------------------------------------------------
J1. Ubuntu ပေါ် ပထမဆုံး တင်သုံးပုံ
--------------------------------------------------------------------------------

  sudo mkdir -p /opt/ceir
  sudo chown -R $USER:$USER /opt/ceir
  cd /opt/ceir
  git clone https://github.com/Phyo-KSPM/backend.git backend
  cd /opt/ceir/backend

  cp .env.example .env
  nano .env
  # DATABASE_URL / REDIS_URL ကို server အမှန်နဲ့ ကိုက်အောင် ပြင်

  npm install
  npm run docker:infra        # သို့ host Postgres/Redis သုံးရင် ကျော်
  npm run db:setup

  npm run pm2:start
  npm run pm2:status

  # optional — reboot ပြီး auto start
  npx pm2 save
  npx pm2 startup


--------------------------------------------------------------------------------
J2. /opt/ceir/backend မှာ အရေးကြီးသော path များ
--------------------------------------------------------------------------------

  /opt/ceir/backend/ecosystem.config.cjs
  /opt/ceir/backend/.env
  /opt/ceir/backend/services/...
  /opt/ceir/backend/logs/<service>-out.log
  /opt/ceir/backend/logs/<service>-error.log

  cwd / script / logs အားလုံး /opt/ceir/backend အောက်ကို ညွှန်းထားသည်။


--------------------------------------------------------------------------------
