B1. လိုအပ်သော software (host)
--------------------------------------------------------------------------------

  [ ] Node.js 20+
  [ ] PostgreSQL (apt)
  [ ] Redis (apt)
  [ ] Git
  [ ] ★ Docker မလို / မသုံး


--------------------------------------------------------------------------------
B2. Host PostgreSQL + Redis တပ်ခြင်း (ဥပမာ Ubuntu)
--------------------------------------------------------------------------------

  sudo apt update
  sudo apt install -y postgresql postgresql-contrib redis-server

  sudo systemctl enable --now postgresql
  sudo systemctl enable --now redis-server

  # DB + user ဥပမာ
  sudo -u postgres psql -c "CREATE USER ceir WITH PASSWORD 'your_strong_password';"
  sudo -u postgres psql -c "CREATE DATABASE app_db OWNER ceir;"
  sudo -u postgres psql -c "GRANT ALL PRIVILEGES ON DATABASE app_db TO ceir;"

  Redis စစ်ရန်:

    redis-cli ping
    # PONG


--------------------------------------------------------------------------------
B3. Project clone + .env
--------------------------------------------------------------------------------

  sudo mkdir -p /opt/ceir
  sudo chown -R $USER:$USER /opt/ceir
  cd /opt/ceir
  git clone https://github.com/Phyo-KSPM/backend.git backend
  cd /opt/ceir/backend

  cp .env.example .env
  nano .env

  .env ဥပမာ (host services):

    DATABASE_URL=postgresql://ceir:your_strong_password@localhost:5432/app_db
    DB_HOST=localhost
    DB_PORT=5432
    DB_USER=ceir
    DB_PASS=your_strong_password
    DB_DATABASE=app_db
    REDIS_URL=redis://localhost:6379
    JWT_SECRET=change-me-in-production

  ★ npm run docker:infra   မလုပ်ရ
  ★ npm run docker:*       မလုပ်ရ

################################################################################
  အပိုင်း B7 — Production security checklist (မဖြစ်မနေ)
################################################################################

  Code မှာ ပါပြီးသား:
    - HS256 JWT + expiry
    - API Gateway auth middleware (token မပါ → 401)
    - Public: POST /login, POST /auth/refresh, POST /bff/login သာ
    - GET /health = localhost / SSH သာ (nginx/public proxy → 404)
    - IMEI / NRC / profile / tax / payments / claims / activities အားလုံး token လို
    - Gateway rate limits: all 120/min, login 20/15min, auth 40/15min, IMEI 30/min (429)
    - ownership checks, weak JWT_SECRET boot-fail, Swagger prod default off
  Server / ops ဘက်မှာ အောက်ပါကို စစ်ပါ။

  ---------- ချက်ချင်း (deploy တိုင်း) ----------

  [ ] 1. api-gateway (:3000) နှင့် bff (:3002) PM2 မှာ online + တည်ငြိမ်
        # Server ပေါ်မှာသာ (public URL မသုံးရ)
        curl -s http://localhost:3000/health
        curl -s http://localhost:3002/health
        # https://service.ceir.gov.mm/health → 404 ဖြစ်ရမယ်

  [ ] 2. JWT_SECRET — အားကောင်း (≥32 chars), environment တစ်ခုချင်း သီးသန့်
        node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
        # .env ထဲ ထည့် — change-me-in-production / short secret မထားရ
        # Production မှာ NODE_ENV=production → weak secret ဖြင့် service မစရ

  [ ] 3. SWAGGER_ENABLED=false  (production)
        # လိုမှ trusted network မှာ SWAGGER_ENABLED=true ယာယီဖွင့်
        # Public: https://service.ceir.gov.mm/docs မဖွင့်ရန်

  [ ] 4. Demo account — production မှာ မသုံးရ / password ပြောင်း
        # Seed: maung@dealer.com / secret123  (local သာ)
        # Prod: password rotate သို့ user disable/delete

  [ ] 5. Firewall — public ဖွင့်ရမည့် ports
        ခွင့်:  22 (SSH), 80/443 (nginx → gateway :3000)
        ပိတ်:  3001 (swagger), 3002 (bff), 3010–3017 (domain),
              5432 (Postgres), 6379 (Redis)
        # Domain services / DB / Redis = localhost သို့ private net သာ


  ---------- မြင့် (နောက်ထပ်) ----------

  [ ] 6. Postgres — default postgres/postgres မထား၊ ခိုင်မာသော password
  [ ] 7. Redis — requirepass + bind 127.0.0.1 (သို့ private)
  [ ] 8. CORS_ORIGINS — browser/app origin allowlist
        ဥပမာ: CORS_ORIGINS=https://service.ceir.gov.mm,https://app.ceir.gov.mm
  [ ] 9. PM2 ကို root မဟုတ် non-root user ဖြင့် run (least privilege)
  [ ] 10. payBatch = simulate သာ — real MPU/KBZ/Wave webhook မထည့်မချင်း
         production fiscal confirmation အဖြစ် မယူရ
  [ ] 11. Dealer verify = local match သာ — IRD integration အစစ် လိုအပ်သေး
  [ ] 12. Device fingerprint ကို mutating API များမှာပါ enforce (login သာမဟုတ်)


  ---------- အလယ် / နိမ့် ----------

  [ ] 13. helmet / security headers (gateway)
  [ ] 14. Gateway-level rate limit (login + IMEI)
  [ ] 15. Claim document URL allowlist / controlled upload
  [ ] 16. Audit log (failed login, pay, verify)
  [ ] 17. npm audit + dependency updates
  [ ] 18. Secrets manager (prod မှာ .env file သက်သက် မထား)


  ---------- Deploy ပြီး smoke (auth) ----------

    # Token မပါ → 401 ဖြစ်ရမယ်
    curl -i https://service.ceir.gov.mm/openapi/v1/profile

    # Login → accessToken ရမှ profile ခေါ်
    curl -s -X POST https://service.ceir.gov.mm/openapi/v1/login \
      -H "Content-Type: application/json" \
      -d '{"email":"...","password":"...","deviceFingerprint":"..."}'

################################################################################
  အပိုင်း G — Troubleshooting
################################################################################

  Windows: Docker daemon is not running
    → Docker Desktop ဖွင့်

  Linux: connection refused :5432 / :6379
    → sudo systemctl status postgresql
    → sudo systemctl status redis-server
    → .env DATABASE_URL / REDIS_URL စစ်

  Linux မှာ docker:infra error
    → Production မှာ Docker မသုံးရ — host Postgres/Redis သုံးပါ

  Port already in use
    → pm2:status / (Windows) docker ps

  relation "users" does not exist
    → npm run db:setup

  Login 401
    → seed + demo password စစ်

  ACCOUNT_BOUND_TO_OTHER_DEVICE
    → တူညီသော deviceFingerprint သုံး
