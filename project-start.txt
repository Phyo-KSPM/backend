--------------------------------------------------------------------------------
1) Git ကနေ ပြန်သုံးပုံ
--------------------------------------------------------------------------------

  git clone https://github.com/Phyo-KSPM/backend.git
  cd backend
  npm install
  copy .env.example .env
  npm run docker:infra
  npm run db:setup
  npm run pm2:start
  npm run pm2:status


--------------------------------------------------------------------------------
2) မ run ခင် (Pre-flight)
--------------------------------------------------------------------------------

  [ ] Node.js 20+          (node -v / npm -v)
  [ ] Docker Desktop       (Running)
  [ ] backend folder သို့ cd
  [ ] npm install
  [ ] .env ရှိ            (မရှိရင် copy .env.example .env)
  [ ] DATABASE_URL / REDIS_URL မှန်
  [ ] Port 5432, 6379, 3000 အလွတ်


--------------------------------------------------------------------------------
3) အဆင့်လိုက် Start (အကြံပြု = PM2)
--------------------------------------------------------------------------------

  STEP 1  Docker Desktop ဖွင့် → Ready

  STEP 2  Infra

            npm run docker:infra
            docker ps --filter "name=ceir-"
            → (healthy) စောင့်

  STEP 3  DB

            npm run db:setup

  STEP 4  Apps (PM2)

            npm run pm2:start
            npm run pm2:status     → online ၁၀ ခု
            npm run pm2:logs       → လိုရင်

          Foreground debug လိုရင်:

            npm run pm2:delete
            npm run dev:all

  STEP 5  Smoke test

            http://localhost:3000/health
            http://localhost:3000/openapi/v1/nrc/townships

            Login:  maung@dealer.com / secret123
                    deviceFingerprint: fp_test_device_001
            IMEI:   359876543210108


--------------------------------------------------------------------------------
4) နေ့စဉ် (schema မပြောင်းရင်)
--------------------------------------------------------------------------------

  1) Docker Desktop ဖွင့်
  2) npm run docker:infra
  3) npm run pm2:start
  4) npm run pm2:status


--------------------------------------------------------------------------------
5) PM2 commands
--------------------------------------------------------------------------------

  npm run pm2:start      စတင်
  npm run pm2:status     အခြေအနေ
  npm run pm2:logs       logs
  npm run pm2:restart    restart
  npm run pm2:stop       ရပ်
  npm run pm2:delete     list ကနေ ဖျက်
  npm run pm2:flush      log ရှင်း

  Config: ecosystem.config.cjs
  Logs:   logs\


--------------------------------------------------------------------------------
6) ရပ်နည်း
--------------------------------------------------------------------------------

  App (PM2):     npm run pm2:stop   သို့  npm run pm2:delete
  App (dev:all): Ctrl + C
  Infra:         npm run docker:infra:down
