ပတ်ဝန်းကျင် မူဝါဒ:

  Windows local     → Postgres + Redis = Docker (npm run docker:infra)
  Linux production  → Postgres + Redis = host packages (Docker မသုံး)


--------------------------------------------------------------------------------
1) Windows local — အမြန် start
--------------------------------------------------------------------------------

  cd C:\Users\rnd\Desktop\project-setup\backend
  npm install
  copy .env.example .env
  npm run docker:infra
  npm run db:setup
  npm run pm2:start
  npm run pm2:status


--------------------------------------------------------------------------------
2) Linux production (/opt/ceir/backend) — Docker မသုံး
--------------------------------------------------------------------------------

  # Host ပေါ် Postgres + Redis တပ်ပြီးမှ (.env ကိုက်အောင် ပြင်)

  cd /opt/ceir/backend
  cp .env.example .env
  nano .env
  # REQUIRED: JWT_SECRET (strong), SWAGGER_ENABLED=false
  # Firewall: only 80/443 public — see project-setup.txt §B7
  npm install
  npm run db:setup
  npm run pm2:start
  npm run pm2:status

  ★ npm run docker:infra  မလုပ်ရ


--------------------------------------------------------------------------------
2b) Linux — production security (အမြန်)
--------------------------------------------------------------------------------

  [ ] JWT_SECRET ≥32 chars (unique)
  [ ] SWAGGER_ENABLED=false
  [ ] Demo password rotate/disable
  [ ] Firewall: block 3001–3017, 5432, 6379
  [ ] curl /health + curl /profile without token → 401

  အသေးစိတ်: project-setup.txt → အပိုင်း B7
