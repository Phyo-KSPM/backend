================================================================================
  CEIR Backend — Project Start Guide
  (အသေးစိတ်လမ်းညွှန်အတွက် project-setup.txt ကို ဖတ်ပါ)
================================================================================

ဤဖိုင်က အမြန် start အတွက် အတိုချုပ်ဖြစ်ပါတယ်။
မ run ခင် ပြင်ဆင်ရမယ့် အရာများ + အဆင့်လိုက် အသေးစိတ်ကို
project-setup.txt ထဲမှာ ရေးထားပါတယ်။


--------------------------------------------------------------------------------
Git ကနေ ပြန်သုံးပုံ (အတိုချုပ်)
--------------------------------------------------------------------------------

  git clone https://github.com/Phyo-KSPM/backend.git
  cd backend
  npm install
  copy .env.example .env
  npm run docker:infra
  npm run db:setup
  npm run dev:all

  အသေးစိတ်: project-setup.txt → အပိုင်း I


--------------------------------------------------------------------------------
မ run ခင် (Pre-flight) — မမေ့ရ
--------------------------------------------------------------------------------

  1. Node.js 20+ တပ်ထား (node -v / npm -v)
  2. Docker Desktop ဖွင့်ထား (Running)
  3. backend folder သို့ cd
  4. npm install
  5. .env ရှိကြောင်း စစ် (မရှိရင် copy .env.example .env)
  6. DATABASE_URL / REDIS_URL မှန်ကြောင်း စစ်
  7. Port 5432, 6379, 3000 အလွတ်ဖြစ်ကြောင်း စစ်


--------------------------------------------------------------------------------
အဆင့်လိုက် Start
--------------------------------------------------------------------------------

  STEP 1  Docker Desktop ဖွင့် → Ready ဖြစ်အောင် စောင့်

  STEP 2  Infrastructure (Postgres + Redis)

            npm run docker:infra

          စစ်ရန်:

            docker ps --filter "name=ceir-"

          (healthy) ဖြစ်သည်အထိ စောင့်

  STEP 3  Migrate + Seed (ပထမဆုံး / schema ပြောင်းရင်)

            npm run db:setup

  STEP 4  App services

            npm run dev:all

  STEP 5  Smoke test

            http://localhost:3000/health
            http://localhost:3000/openapi/v1/nrc/townships

              email: maung@dealer.com

--------------------------------------------------------------------------------
နေ့စဉ် (schema မပြောင်းရင်)
--------------------------------------------------------------------------------

  1) Docker Desktop ဖွင့်
  2) npm run docker:infra
  3) npm run dev:all


--------------------------------------------------------------------------------
ရပ်နည်း
--------------------------------------------------------------------------------

  App:   Ctrl + C
  Infra: npm run docker:infra:down
